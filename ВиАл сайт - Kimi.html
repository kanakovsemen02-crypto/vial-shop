1️⃣ Как открыть сайт у себя

  1. Скачайте файл vial-shop.html (кнопка выше)
  2. Найдите его в папке «Загрузки»
  3. Дважды кликните по файлу — он откроется в браузере (Chrome, Edge, Яндекс.Браузер)
Всё, сайт работает прямо у вас на компьютере.

2️⃣ Как добавлять товары (без программирования)

  1. Откройте сайт в браузере
  2. В верхнем меню нажмите «➕ Добавить запчасть»
  3. Заполните поля: название, категория, цена, описание
  4. Нажмите «Выберите файл» и загрузите фото товара с компьютера или телефона
  5. Нажмите «Добавить в каталог» — товар сразу появится в списке
⚠️ Важный нюанс: товары сохраняются только в том браузере, где вы их добавили. Если открыть сайт на другом устройстве — новых товаров там не будет. Поэтому дальше нужен шаг 3.

3️⃣ Как выложить сайт в интернет (бесплатно)

Самый простой способ — GitHub Pages:
  1. Зайдите на github.com и зарегистрируйтесь
  2. Создайте новый репозиторий (кнопка «New»), назовите, например, vial-shop
  3. Нажмите «Upload files» и загрузите файл vial-shop.html, переименовав его в index.html
  4. Зайдите в Settings → Pages → выберите ветку main → Save
  5. Через 2–3 минуты сайт будет доступен по адресу вида ваш-логин.github.io/vial-shop
Теперь им можно делиться с клиентами, а товары добавлять через кнопку в меню.

4️⃣ Как изменить текст самому (телефон, адрес, цены)

Файл сайта — это обычный текст, который можно править:
  1. Кликните по файлу правой кнопкой → Открыть с помощью → Блокнот (или Notepad++)
  2. Найдите нужный текст (например, +7 (347) 2XX-XX-XX)
  3. Замените на свой номер, сохраните файл (Ctrl+S)
  4. Обновите страницу в браузере — изменения появятся
⚠️ Меняйте только текст между тегами, сами символы < > не трогайте.

5️⃣ Хотите стать разработчиком?

Вот минимальный путь, чтобы понимать и дорабатывать такие сайты сами:
  1. HTML (1–2 недели) — структура страницы: тексты, картинки, кнопки. Учите на htmlacademy.ru или freeCodeCamp (бесплатно)
  2. CSS (2–3 недели) — оформление: цвета, шрифты, расположение, адаптивность под телефон
  3. JavaScript (1–2 месяца) — логика: корзина, формы, добавление товаров (именно он делает сайт «живым»)
После этого сможете не только править мой сайт, но и создавать свои с нуля. Практика: откройте мой файл в Блокноте и попробуйте поменять цвет — найдите строку --red:#e03131 и впишите другой цвет, например #1c7ed6 (синий).
